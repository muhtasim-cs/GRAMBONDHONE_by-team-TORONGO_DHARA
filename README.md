## 🏛️ Module Overview & Features

### 1. 🌟 Landing Page & Hero Section
- **Files**: `index.html`, `homepage.html`, `src/hero-section.ts`, `src/homepage.ts`, `css/hero-section.css`, `css/homepage.css`
- **Authentic Hero Slideshow**: Continuous 2.0s crossfade carousel showcasing Bangladeshi rural agriculture (paddy transplanting, mustard honey harvest, Sylhet tea gardens) without pausing on hover.
- **Halal Investment Spotlight**: Features active ethical campaigns with bilingual Mudarabah return badges (`৩৫% বিনিয়োগকারীর সরাসরি মুনাফা`).
- **Interactive Dual-Track "How It Works"**: Step-by-step visual roadmap for both Conscious Investors and Rural Producers.

### 2. 🤖 Bondhon AI Chatbot (বন্ধন এআই)
- **Files**: `src/chatbot.ts`, `src/styles/chatbot.css`, `public/images/chatbot-logo.svg`, `public/images/chatbot-logo.png`
- **Features**:
  - **Bilingual Conversational AI**: Native comprehension in both Bengali (বাংলা) and English.
  - **Contextual Financial Intelligence**: Instantly answers questions regarding Shariah Mudarabah profit-sharing ratios, risk forecasting, crop insurance, and verification deeds.
  - **Direct Deal Recommendation**: Suggests active agricultural projects matching the investor's budget.
  - **Persistent Floating Widget**: Interactive chat toggle with unread badges, typing animations, quick suggestion chips, and sound cues.

### 3. 💼 Investor Ecosystem
- **`investor_dashboard.html`**: Overview featuring the dark green `#02221A` theme, metric stat cards (Total Balance ৳ 4,85,000, Total Profit ৳ 84,250), and live field activity logs.
- **`investor_projects.html`**: 30 verified agricultural projects across Bangladesh with the interactive **Investment Return Calculator**.
- **`investor_financials.html`**: The redesigned **2×2 Compact Capital Outflow & Return Inflow Ledger** ensuring GAAP double-entry transparency and Shariah reconciliation.
- **`investor_airisk.html`**: AI-driven crop yield predictive modeling and satellite precipitation index mapping.
- **`investor_marketplace.html`**: Wholesale rural handicraft investment contracts and artisan collective profiles.
- **`investor_profile.html`**: National ID KYC badge, Islami Bank Bangladesh Ltd (IBBL) Mudarabah accounts, and bKash/Nagad payout wallets.

### 4. 🛒 Village Marketplace & Orders
- **Files**: `marketplace.html`, `orders.html`, `src/marketplace.ts`
- **Features**: 100 authentic Bangladeshi rural products priced in Taka (৳), instant search autocomplete, category filter chips, shopping bag drawer, and multi-stage delivery timeline tracking.

## 🚀 How to Run Locally

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the Development Server
```bash
npm run dev
```
The server will start at: **`http://localhost:5173`**

### 3. Production Build
```bash
npm run build
```
